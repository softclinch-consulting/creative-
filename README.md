# creative-

## Building Tomorrow — Construction & Architectural Scrollytelling Experience

A luxury scroll-driven storytelling website engineered with React, TypeScript, Tailwind CSS, Framer Motion, and hardware-accelerated HTML5 Canvas frame sequencing.

### Key Highlights
- **150-Frame Scrollytelling Engine**: Continuous transformation from empty land to completed luxury villa driven strictly by scroll progress.
- **Pure Image-Based**: Zero video element overhead, progressive image batch caching, and 60fps canvas rendering.
- **Ultra-HD Architectural Backdrops**: Crisp 2560px backgrounds across full-body content and footer.
- **Interactive Features**: Construction process timeline, project enquiry form, case study viewer, and interactive scrub bar.

### Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

### Development
```bash
npm install
npm run dev
npm run build
npm run preview
```
